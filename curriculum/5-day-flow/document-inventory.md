## How the trainee fixes a challenge

| Route | What the trainee does |
|---|---|
| `cms` | Correct our own record in the CMS, with a note citing the source document |
| `amend` | Amendment Request to the provider (Email Workspace), with Atty. Thorne's approval; the provider corrects its own record |
| `records` | Request it through ChartSwap (Medical Records Requests) on a live HIPAA authorization |
| `docket` | Docket the correct date (Court E-Filing · CMS → Calendar), counted from the right event |
| `redline` | Redline it and route it to Atty. Thorne before anyone signs or serves it |
| `route` | Route it to Atty. Thorne the same day; the decision is his |
| `audit` | Work it item by item in the exhibit audit (keep · replace · pull · add · flag) |
| `qc` | Fix the copy before it goes into any set (re-export, certify, replace) |
